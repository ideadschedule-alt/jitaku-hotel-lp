# 自宅ホテル化計画 LP

内装デザインから施工、完成後のリネン・アメニティの継続サービスまでを紹介するランディングページです。

## 主な内容

- リビング・寝室を中心としたリノベーション
- 内装デザインから工事までの一貫対応
- ホテル仕様のリネンサービス
- ルームフレグランス・アメニティの定期配送

## 開発環境

- Node.js 22.13.0 以上
- React / vinext / Vite

## 起動方法

```bash
pnpm install
pnpm run dev
```

ローカルプレビューは `http://localhost:3000/` です。

## ビルド

```bash
pnpm run build
```

## 主な編集箇所

- `app/page.tsx`：LP本文・構成
- `app/globals.css`：デザイン・レスポンシブ表示
- `app/layout.tsx`：ページタイトル・概要
- `public/images/`：LP内の画像

## 公開前に確認する項目

- 無料相談ボタンの正式な遷移先
- 取扱ホテル・フレグランスブランドの確定情報
- 施工費と月額サービス価格
- 利用条件、最低契約期間、対応エリア

## 写真素材

一部の写真は Pexels の無料素材を使用しています。生成したオリジナルの室内イメージも含まれます。
